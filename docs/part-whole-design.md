# Part-Whole Game Design

## Curriculum Mapping

- **Strand:** Numeracy
- **Level:** 4 (Age 5-6)
- **Path:** Follows `compare`, leads to `sums`.

## Screen Flow (Number Balance)

The core metaphor is a physical balance scale. The child places objects or number weights on either side of the scale to balance it, learning that two smaller parts make up a whole, and that quantities can be equivalent.

1. The game starts with a target number/quantity on one side of the scale (the whole).
2. The child is prompted to drag elements (e.g., apples, blocks, or number weights) onto the other side (the parts).
3. As items are added, the scale visually tilts until it reaches equilibrium when the quantities match.
4. An auditory and visual celebration confirms the match (e.g., "3 and 2 makes 5!").

## 3-Level Ramp

- **Level 1 (Visual/Countable parts):** The scale has a set number of distinct objects on one side (e.g., 5 apples). The child drags individual apples to the other side to balance it.
- **Level 2 (Mixed quantities):** One side has a target numeral (e.g., "6"). The child drags groups of items (e.g., a basket of 4 and a basket of 2) to balance the numeral.
- **Level 3 (Number weights):** Both sides use number weights. The child must pick two weights (e.g., a "3" and a "4") to balance a single target weight (e.g., "7").

## Assets Needed

- **Scale:** A visual balance scale with two trays, capable of animating tilt.
- **Weights/Objects:** Apples, blocks, and number weights (1-10).
- **Audio:** Voiceovers for "Balance the scale", "Make [number]", and confirmation phrases (e.g., "equal!", "4 and 3 is 7").
