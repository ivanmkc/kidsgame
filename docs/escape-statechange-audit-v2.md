# Escape State-Change Audit v2: Seamless Full-Scene Chain

## What went wrong in v1

The first implementation used **bbox-sized patch crops** overlaid at hotspot
coordinates. Every after-patch was the exact rectangle of the SAM-detected
hotspot box. This violated three properties the diff/hidden pipeline already
gets right:

### 1. No room for the open state

A chest lid that opens extends *above* the closed-chest bounding box. A gate
that swings out extends *beyond* its closed-gate bbox. The v1 approach
hard-clipped at the box boundary, so open lids were sliced mid-hinge and
swing-open gates were cut at the frame edge. The diff/hidden pipeline never
hits this because it uses `changed_bbox` (tight bbox of the **changed pixels**,
which includes the full extent of the new object) rather than the original
detection box.

### 2. No mask growth for soft edges and shadows

In `scenes_sam.py` and `scenes.py`, SAM masks are **dilated** before being used
as edit regions — the context ring around the object lets NBP paint soft edges,
cast shadows, and anti-alias naturally. The diff pipeline's `edit_local` uses
a `ctx` parameter (typically 80–110 px) that pads the crop, and the
`_object_composite` function feathers the blend using morphological operations
(MaxFilter → MinFilter → GaussianBlur). The v1 escape code used `edit_local`
for the NBP call (correctly), but then **cropped the result to the original
bbox** and saved only that crop as the patch — discarding the feathered edge,
the shadow skirt, and any part of the open state that extended beyond the box.

### 3. Rectangular seam at the overlay edge

Compositing a bbox-sized PNG over the base image at exact box coordinates
produces a hard rectangular boundary. Even if the NBP edit inside the box is
perfect, the edge pixels don't blend — the overlay sits on top like a sticker.
The diff pipeline avoids this by compositing with `_object_composite`, which
blends only genuinely-changed pixels with a feathered alpha mask. The v1 escape
patches had no feathering at all: the crop edge IS the composite boundary.

## The fix: full-scene state chain

Instead of patch crops, each state-changing hotspot generates a **full-scene
image** where the edit has been applied. Since NBP's `edit` function with
`_object_composite` guarantees byte-identical pixels outside the mask, the
full-scene image differs from its predecessor only in the edited region — there
is no seam by construction.

### Chain structure

Escape rooms are linear dependency chains (the lint verifies this). The state-
changing hotspots form a strict subsequence of the chain:

- **toyroom**: chest (s1) → pen (s2)
- **dragoncave**: stove (s1) → dragon (s2)
- **rocketpad**: rocket (s1) → crate (s2) → button (s3)
- **piratecove**: pelican (s1) → chest (s2)

State image k is generated by applying NBP `edit` to state image k-1 (where
state 0 = the original scene). Each edit uses an **expanded mask** (1.6× the
hotspot box, plus room for lids/gates/steam/shadow) so the open state has space
to breathe.

### Manifest change

Old: `hotspot.after = { x, y, w, h, patch: 'escape/room_id_after.png' }`
New: `hotspot.afterScene = 'escape/room_s1.png'`

Each afterScene is a full 1280×720 image. The runtime crossfades the entire
scene image (400ms opacity) — since pixels outside the edit region are identical,
only the object visibly transforms.

### Judge criteria

Every state image is judged for three properties:

1. **Identical outside the region**: pixel diff outside the expanded mask must
   be below the drift threshold (same gate as `edit_local`).
2. **Believable open/used state**: the edited region must show the prompted
   after-state naturally.
3. **No rectangular seam or clipped parts**: the open state must not show a hard
   edge, cut-off lid, or box outline.

### What we stopped doing

- Saving bbox-sized crop PNGs (deleted: 9 `*_after.png` files)
- The `EscapeAfter extends Box` type (replaced by `afterScene: string`)
- The `AfterPatch` component with per-crop positioning (replaced by whole-scene
  crossfade)
- `edit_local` for escape edits (replaced by full-frame `edit` with expanded mask)
